# 自定义字体文件夹

想给海报增加新字体，照下面三步：

1. 在本文件夹里**新建一个子文件夹**，名字就用你想显示的字体名（也会作为 CSS 字体名），例如 `优设标题黑/`。
2. 把字体文件（`.woff2` / `.woff` / `.ttf` / `.otf`）放进那个子文件夹。
   - 文件名里若带 `700`、`300` 等数字，会被识别为字重；带 `italic` 视为斜体。
   - 想指定只在中文或英文下拉出现，可在子文件夹里放一个 `meta.json`，内容如 `{"lang":"cn"}`（可选值：`cn` / `en` / `both`，默认 `both`）。
3. 重新构建（`npm run build`）或开发时重启（`npm run dev`）即可——会自动扫描本文件夹、刷新字体下拉。
   也可单独运行 `npm run scan-fonts` 只刷新清单。

> 内置字体（方正风雅宋、优设标题圆、钉钉进步体、抖音美好体、Cormorant Garamond、Melete 五字重）不在本文件夹，已随程序打包，开箱即用。
> 请只放你有权使用的字体；版权由放置者负责。

`manifest.json` 是自动生成的清单，不用手动编辑。
